# RAG AI Agent - Knowledge Assistant

## Project Overview
This project is an interactive Retrieval-Augmented Generation (RAG) AI Agent built using Streamlit, LangChain, and Groq. It enables users to upload PDF documents (such as academic research papers or thesis reports) and ask questions to extract precise, context-based answers instantly.

## Tools Used
- **Python** (Core Programming Language)
- **Streamlit** (User Interface & Interactive Web App)
- **LangChain** (RAG Architecture & Document Chaining)
- **Groq API** (Fast LLM Inference)
- **ChromaDB / HuggingFace Embeddings** (Vector Indexing & Semantic Search)

## Key Features
- **PDF Document Processing:** Automatically parses and indexes large PDF files into searchable vector chunks.
- **Context-Aware Responses:** Answers user queries strictly based on the content of the uploaded document.
- **Interactive Chat Interface:** Clean and modern conversation UI with clear chat history and source citations.
- **Fast Execution:** Powered by high-speed inference models for near-instant responses.
